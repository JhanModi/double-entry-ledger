# Demo transcript

A real, unedited run of [`scripts/demo.sh`](../scripts/demo.sh), so the system's behavior can be seen without running it. Every `[ok]` line is a check the script made against the live API; any other response would have stopped it with `[FAILED]`.

- **When:** 2026-10-04, during M7, on the code in this repository at that milestone.
- **Where:** Windows 11, Git Bash, curl 8.7.1, jq 1.8.2, Java 25. The app ran from its jar against PostgreSQL 18 in Docker Compose, on the same machine.
- **Ids differ on every run.** They're UUIDv7s, generated by Postgres. Each run creates its own two clients, so it can be repeated on the same database.
- **No API keys appear** in this output: the script keeps them in a temporary file and never prints them.

To run it yourself, see [Run it locally](../README.md#run-it-locally) in the README.

What to look for:
- **Step 5:** the retried request gets the original transfer back, marked `Idempotent-Replayed: true`, and the balances don't move.
- **Step 9:** another client's account and an id that doesn't exist get exactly the same 404.
- **Step 10:** ten copies of one request, sent at the same moment, move the money once.
- **Step 11:** thirty transfers race for $260.00, and exactly 26 succeed. The account ends at $0.00, never below.
- **Step 12:** the balance equals the sum of its entries, to the cent.
